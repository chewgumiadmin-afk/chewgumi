메일 서식 복사

Supabase 가입 확인·비밀번호 재설정 메일을 츄구미 서식으로 바꿉니다.
단추를 눌러 복사한 뒤 Supabase 대시보드에 붙여넣으세요.

어디에 넣나요

Supabase 대시보드 → Authentication → Emails → Templates

대시보드 열기 →
  1. 왼쪽에서 Confirm signup 선택
  2. 아래 제목 복사 → Subject heading 에 붙여넣기
  3. 아래 본문 복사 → Message body 를 통째로 바꾸기
  4. Save
  5. Reset password 도 같은 방법으로

① 회원가입 확인

로고 + 트래블잇·듀잇 사진이 들어갑니다.
