# 검증 도구

## 정적 검사 (lint)
```
python3 tools/verify.py
```
문법 · 링크 · 접근성 · 모바일 UX · 성능 · SEO · 비밀키 노출을 검사합니다.
사전에 `lint/` 폴더에 페이지를 내려받아야 합니다.

## 단위 테스트 · 시나리오
```
node tools/test.js
```

**단위 테스트**
- 상품 매칭 `matchId()` — 11종 + 예외
- 금액 계산 `quote()` — 배송비, 무료배송 기준, 쿠폰 3종
- 예외 처리 — 빈 장바구니, 없는 상품, 재고 초과, 잘못된 수량, 만료 쿠폰
- 주문번호 · 입금기한 (월·연 넘김)
- 주문 상태 전이 규칙
- 택배사 자동 인식
- 광고 발송 시간 제한 (정보통신망법)
- 문자 과금 구분 (SMS/LMS)

**시나리오**
1. 무통장입금 정상 구매 (장바구니 → 견적 → 쿠폰 → 주문 → 알림 → 입금 → 발송 → 완료)
2. 입금 전 취소
3. 입금 후 발송 전 취소 (전액 환불)
4. 배송 후 반품 (왕복 배송비 차감)
5. 취소 예외 (중복 취소, 사유 누락)
6. 재고 부족 주문 실패
7. 정기구독 신청 → 발송 → 중지 → 재개 → 해지
8. 광고 문자 발송 규정 (수신 동의, 시간 제한)

## 주의
테스트의 계산 로직은 서버(Edge Function)와 **같은 규칙을 복제**한 것입니다.
서버 로직을 바꾸시면 `tools/test.js`도 함께 수정해야 합니다.
