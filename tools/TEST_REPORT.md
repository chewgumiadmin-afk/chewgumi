## 4. 이 테스트가 잡지 못하는 것

정직하게 적어둡니다.

- **계산 로직을 복제해 검증한 것**입니다. 서버(Edge Function) 코드를 직접 실행하지 않습니다.
  서버 로직을 바꾸면 `tools/test.js`도 함께 고쳐야 합니다.
- **브라우저 동작은 검증하지 않습니다.** 버튼이 실제로 눌리는지, 팝업이 뜨는지,
  이미지가 문구와 맞는지는 사람이 봐야 합니다.
- **결제 연동(PG)** 은 테스트 대상이 아닙니다. 실제 결제는 별도 검증이 필요합니다.
- **이메일·문자 실제 발송** 은 시나리오상 가정이며, 발송 성공 여부는 확인하지 않습니다.
