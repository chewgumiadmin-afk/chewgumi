# 6단계 · 토큰 받기

## 6-1. 그래프 API 탐색기 열기

```
https://developers.facebook.com/tools/explorer/
```

또는 앱 화면 위쪽 **[도구] → [그래프 API 탐색기]**

## 6-2. 오른쪽 위에서 고르기

화면 오른쪽에 상자가 셋 있습니다.

| 칸 | 고를 것 |
|---|---|
| Meta 앱 | **chewgumi** |
| 사용자 또는 페이지 | **페이지 액세스 토큰** |
| 페이지 | **ChewGumi 츄구미** (연결된 페이지) |

> 「사용자 토큰」이 아니라 **「페이지 토큰」** 입니다.

## 6-3. 권한 고르기

아래 **「권한」** 목록에서 넷을 체크하세요.

```
instagram_basic
instagram_manage_insights
pages_show_list
pages_read_engagement
```

**검색칸에 이름을 넣으면** 빨리 찾습니다.

## 6-4. 토큰 만들기

```
[액세스 토큰 생성] 누르기
→ 페이스북 로그인 창이 뜹니다
→ 「계속」 → 권한 「모두 허용」
```

**주소칸 위에 긴 글자**가 나타납니다. `EAAxxxx…` 로 시작합니다.

## 6-5. 잘 되는지 확인

주소칸에 이것을 넣고 **[제출]**

```
17841444679205755?fields=username,followers_count,media_count
```

**이렇게 나오면 성공입니다.**

```json
{
  "username": "chewgumi_official",
  "followers_count": 123,
  "media_count": 45,
  "id": "17841444679205755"
}
```

**오류가 나면** 6-3 권한을 다시 보세요.
