# 네이버 커머스 API · 고정 IP 만들기

네이버가 준 두 방법 중 **② 프록시 경유**를 권합니다.

```
① AWS VPC + NAT      사흘 · 월 5만원 · AWS 계정 관리 필요
② 프록시 경유         하루 · 월 1~3만원 · 지금 구조 유지  ← 권함
```

**②로 안내드립니다.** ①을 원하시면 말씀해 주세요.

---

# 왜 ②가 나은가

**지금 Supabase Edge Function 을 그대로 씁니다.**
나가는 길만 프록시를 거치게 하면 됩니다.

```
지금   Edge Function  →  (IP 매번 바뀜)  →  네이버  ✕
후     Edge Function  →  프록시(고정 IP)  →  네이버  ✓
```

AWS 계정을 따로 만들거나 관리할 필요가 없습니다.

# 1단계 · 프록시 계정 만들기

## 1-1. 가입

```
https://www.quotaguard.com
→ [Get Started] → 이메일로 가입
```

## 1-2. 요금제 고르기

```
Static — Micro ($19/월)
고정 IP 2개 · 월 20GB
```

**주문 수집 정도면 충분합니다.**

## 1-3. 접속 정보 받기

가입하면 대시보드에 이런 것이 나옵니다.

```
QUOTAGUARDSTATIC_URL
http://아이디:비밀번호@static.quotaguard.com:9293
```

**고정 IP 두 개**도 함께 나옵니다.

```
1.2.3.4
5.6.7.8
```

## 1-4. 확인

```
□ URL 을 복사해 두셨나요
□ IP 두 개를 적어 두셨나요
```

**저에게 주실 것** — 위 URL 하나입니다.

# 2단계 · 네이버에 IP 등록

```
https://apicenter.commerce.naver.com
→ 판매자 계정으로 로그인
```

## 2-2. 애플리케이션 만들기

```
[애플리케이션 관리] → [애플리케이션 등록]
```

| 칸 | 넣을 것 |
|---|---|
| 이름 | 츄구미 자사몰 |

```

```

**세 개까지 넣을 수 있습니다.** 두 개면 충분합니다.

## 2-4. 키 받기

```
애플리케이션 ID
애플리케이션 시크릿
```

**둘 다 저에게 주시면** 됩니다.

## 2-5. 확인

```
□ IP 가 등록됐나요
□ 애플리케이션 ID · 시크릿을 받으셨나요
```
