## 1. 카페24 API — 이미 열려 있습니다

### 무엇을 가져올 수 있나

카페24는 **매출통계 API를 따로 제공**합니다. 제가 걱정했던 것보다 훨씬 넓습니다.

```
상점 · 상품 · 주문 · 회원 · 게시판 · 디자인
프로모션 · 상품분류 · 판매분류 · 공급사 · 배송
매출통계 · 적립금 · 알림 · 접속통계
```

**대시보드 API**로 주문 현황과 매출 현황을 요약해 받을 수 있고,
**접속통계 API**로 어디서 들어왔는지도 볼 수 있습니다.

### 지금 상태

```
앱 키       등록됨
연동 승인   아직 안 함  ← 이것만 하시면 됩니다
```

`shop.chewgumi.com/cafe24.html` 에서 **[연동 승인하기]** 한 번이면 끝납니다.

### 승인하시면 되는 것

- 카페24 주문이 자사몰로 **자동으로** 들어옵니다 (지금은 메일 붙여넣기)
- 재고가 양쪽에서 **함께** 줄어듭니다
- 매출 통계를 하나로 모아 봅니다

### 주의할 점

버전이 날짜로 관리됩니다. 최신은 `2026-03-01` 입니다.
호출할 때 `X-Cafe24-Api-Version` 을 지정하지 않으면 앱 등록 시점 버전으로 동작합니다.

## 2. 웹 푸시 — 앱 설치 없이 됩니다

### 결론

**2023년 iOS 16.4부터 아이폰에서도 웹 푸시가 됩니다.**
2026년 지금은 안드로이드·PC·아이폰 모두 지원합니다.

### 다만 아이폰만 한 단계 더

| 기기 | 필요한 것 |
|---|---|
| 안드로이드 · PC | 「알림 허용」 누르기만 |
| **아이폰** | **사파리에서 「홈 화면에 추가」 먼저** |

아이폰은 홈 화면에 추가해야 알림이 옵니다.
카카오톡·인스타그램 안에서 열린 화면에서는 동작하지 않습니다.

### 만들 것

```
서비스 워커 파일 하나
알림 허용 받는 버튼
보내는 서버 기능 하나
구독 정보 담을 표 하나
```

**이틀이면 됩니다.** 비용은 들지 않습니다.

### 어디에 쓸 수 있나

```
고객   주문 확인 · 발송 안내 · 재입고 알림 · 쿠폰
관리자 새 주문 · 품절 임박 · 입금 확인
```

## 3. 사진 자동 분석 — 오늘도 가능합니다

### 무엇이 되나

폰에서 사진을 여러 장 올리면 AI가 하나씩 보고 정리합니다.

```
이 사진 — 매대 진열 · 듀잇 레몬민트 12개 · 눈높이 아래
        진열 위치를 한 칸 올리면 좋겠습니다

이 사진 — 경쟁 제품 · 자일리톨 캔디 3종 · 가격 4,900원
        우리보다 1,000원 쌉니다

이 사진 — 고객 후기용 · 밝기 좋음 · 배경 정돈 필요
```

### 만들 것

```
사진 여러 장 올리는 화면
AI에 보내 분석 받기
결과를 DB에 쌓기
날짜·장소별로 모아 보기
```

**하루면 됩니다.** AI 사용료만 듭니다. 사진 한 장에 20~50원쯤입니다.

### 함께 만들면 좋은 것

**장소 마케팅 기록** — 오늘 어디 갔고 무엇을 했는지

```
① 장소 고르기 (또는 위치로 자동)
② 사진 찍어 올리기
③ 무엇을 했는지 고르기 (진열 · 시식 · 상담 · 배부)
④ [다음 장소로]
```

**하루 마치면 정리해서 보여줍니다.** 몇 곳을 돌았고, 무엇을 했고,
사진에서 눈에 띈 것은 무엇인지요.

## 4. 거래처 자동 응대 — 만들 수 있습니다

### 다이식품 같은 제조사와의 흐름

```
① 배합 요청서 만들기      AI가 초안 작성
② 메일 보내기            자동 발송 + 기록
③ 답장 받으면 요약        핵심만 뽑아 알림
④ 중요한 것은 문자로       납기 · 단가 · 시험 결과
⑤ 진행 상황 한 곳에        어디까지 왔는지
```

### 만들 것

```
거래처 표          이름 · 담당자 · 메일 · 전화 · 하는 일
주고받은 것 표      보낸 것 · 받은 것 · 요약 · 상태
메일 보내기         이미 있음 (Resend)
메일 받아 읽기      새로 필요 (Resend Inbound)
문자 보내기         솔라피 키 필요
AI 요약·초안       이미 있음
```

**사흘이면 됩니다.** 문자비만 듭니다. 건당 20원쯤입니다.

### 메디잇과의 배합 데이터 창구

말씀하신 것을 정리하면 이렇습니다.

```
츄구미가 요구사항을 넣습니다
  단맛 정도 · 산도 · 식감 · 향 · 자일리톨 비율

메디잇이 배합안을 올립니다
  원료 · 비율 · 예상 단가 · 시험 결과

양쪽이 같은 표를 봅니다
  시도한 배합 · 관능 평가 · 채택 여부

AI가 정리합니다
  이 조합은 앞서 3번 시도했고 산도가 높다는 평이 있었습니다
```

**DB만 잘 짜면 됩니다.** 나흘쯤 걸립니다.
메디잇 쪽 담당자와 어떤 항목을 주고받을지 먼저 정하셔야 합니다.

## 5. 법인카드 자동 기입 — 어렵습니다

### 왜 어려운가

카드사 API를 직접 쓰려면 **마이데이터 사업자 자격**이 필요합니다.
개인 개발자나 작은 회사가 받기 어렵습니다.

### 대신 쓸 수 있는 것

| 방법 | 어떻게 | 비용 |
|---|---|---|
| **지출관리 SaaS** | 비즈플레이 · 고위드 · 스펜딧 | 월 10~30만 |
| **중개 API** | SION.LAB 같은 곳 | 건당 과금 |
| **엑셀 내려받기** | 카드사에서 받아 올리기 | 무료 |

### 권해드리는 것

**엑셀 내려받아 AI가 분류하는 방식**이 지금은 가장 현실적입니다.

```
① 카드사에서 이용 내역 엑셀 받기 (한 달에 한 번)
② 우리 화면에 올리기
③ AI가 계정과목을 자동으로 붙임
   원료비 · 포장비 · 광고비 · 운송비 · 접대비 …
④ 확인하고 저장
⑤ 매출과 함께 손익 보기
```

**이틀이면 됩니다.** 비용은 AI 사용료뿐입니다.

나중에 규모가 커지면 비즈플레이 같은 곳으로 넘어가시면 됩니다.
그때는 API 연동으로 자동화할 수 있습니다.

## 6. 영상 · 이미지 자동 제작

### 이미지 — 됩니다

```
Google Gemini (Imagen)   건당 30~50원
OpenAI (GPT Image)       건당 60~100원
```

**포스터 · 배너 · 상세 이미지 · SNS 카드**를 만들 수 있습니다.
목적과 크기를 넣으면 여러 안을 뽑아 보여드립니다.

```
"인스타 정사각형 · 듀잇 레몬민트 · 여름 · 시원한 느낌"
→ 네 가지 안 → 고르기 → 다듬기
```

### 영상 — 아직 이릅니다

```
Google Veo      8초에 400~600원 · 품질 좋음
OpenAI Sora     아직 API 제한적
```

**8초짜리 짧은 것**은 만들 수 있지만,
**광고 영상**으로 쓸 만한 30초 이상은 아직 어색합니다.

**권해드리면** — 지금은 이미지를 여러 장 만들어 이어 붙이는 방식이
훨씬 자연스럽고 쌉니다. 영상 API는 반년쯤 뒤에 다시 보시는 게 좋겠습니다.

### 만들 것

```
목적 고르기        인스타 · 상세페이지 · 포스터 · 배너
크기 자동 맞춤      1:1 · 4:5 · 9:16 · 1630:760
브랜드 색·글꼴 고정  분홍 그러데이션 · SUIT · Poppins
여러 안 뽑기        네 개씩
고르고 다듬기
메디잇 검토 요청     만든 것을 보내 확인받기
```

**나흘이면 됩니다.**

## 7. 매출 분석 · 투자처 찾기

### 자사 데이터로 할 수 있는 것

```
어느 상품이 잘 팔리나
어느 구성이 마진이 좋나
어디서 들어와 사나 (카페24 접속통계 API)
언제 많이 사나
재구매율이 어떤가
```

**이건 지금 데이터로 바로 됩니다.**

### 외부 데이터가 필요한 것

「성공 기업 패턴 분석」은 **공개 데이터가 부족**합니다.

| 원하시는 것 | 현실 |
|---|---|
| 경쟁사 매출 | 비공개 (상장사 아니면 못 봄) |
| 네이버 검색량 | **가능** — 데이터랩 API 무료 |
| 인스타 반응 | 자사 계정만 가능 |
| 업종 평균 | 통계청 · 공정위 자료 일부 |

### 권해드리는 것

**네이버 데이터랩 API**를 먼저 붙이시면 좋겠습니다.

```
자일리톨 캔디 검색량이 언제 오르나
비타민 젤리를 누가 찾나 (성별 · 나이)
우리 브랜드명 검색이 늘고 있나
```

**무료**이고 **하루면** 붙입니다.
