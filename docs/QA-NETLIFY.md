# netlify 시험 배포에서 QA 하기

진짜 가게는 **GitHub Pages** 에서 돕니다 — `shop.chewgumi.com` (`CNAME`)
시험은 **netlify** 에서 합니다 — `chewgumi-qa-preview.netlify.app`

같은 코드를 보지만 주소가 다릅니다. 시험하다 무엇이 깨져도 손님은 영향이 없습니다.

`netlify.toml` 이 후처리를 꺼 두었기 때문에 두 곳의 **주소 모양이 같습니다**
(`login.html` 이 `/login` 으로 바뀌지 않습니다). 그래서 시험 결과를 그대로 믿어도 됩니다.
**그 파일은 건드리지 마세요.**

> **데이터는 한 곳(Supabase)을 같이 씁니다.**
> 시험 배포에서 넣은 주문도 진짜 주문 목록에 들어갑니다.
> 결제까지 해보실 때는 `qa-run.html` 안내대로 하시고 끝나면 꼭 취소해 주세요.

## 1. 세 가지 중에 고르시면 됩니다

### ㄱ. 두 칸 시험대 — 컴퓨터에서 (가장 쉽습니다)

    https://chewgumi-qa-preview.netlify.app/qa-lab.html

왼쪽에 화면, 오른쪽에 적는 칸입니다.

1. 위에서 볼 화면을 고릅니다 (고객 34 · 관리자 34 = 68개)
2. **[기록 시작]**
3. 왼쪽에서 평소처럼 눌러봅니다 — 누른 것이 오른쪽에 쌓입니다
4. 이상하면 오른쪽에 적고 **[버그]**

누르는 순간 **왼쪽 화면을 사진으로 찍어** 이슈와 함께 보냅니다.

### ㄴ. 떠다니는 창 — 폰에서

주소 뒤에 `?qa=1` 만 붙이면 됩니다.

    https://chewgumi-qa-preview.netlify.app/checkout.html?qa=1

오른쪽 아래 작은 검은 창이 따라다닙니다. 한 번 켜면 다른 화면으로 옮겨도 따라옵니다.
끄실 때는 그 창의 **✕**.

### ㄷ. 크롬 확장 프로그램

`extension/` 폴더를 크롬 `확장 프로그램 → 압축해제된 확장 프로그램을 로드`.
`v1.1.0` 부터 netlify 시험 배포에서도 됩니다.

## 2. 이슈에 무엇이 같이 담기나

**적으실 것은 「무엇이 이상한지」 한 줄**뿐입니다. 나머지는 도구가 붙입니다.

| 담기는 것 | 보기 | 어디에 |
|---|---|---|
| 어느 화면인지 | `cart.html` | `page` 칸 |
| 기기·브라우저 | `아이폰 · 사파리` | `device` 칸 |
| 화면 크기 | `390×844` | `viewport` 칸 |
| **화면 사진** | 그 순간 보이던 그대로 | `shot_url` → `qa-shots` 창고 (비공개) |
| 정확한 주소 | `https://…/cart.html?qa=1` | `note` 안 |
| 마지막으로 누른 곳 | `#btnBuy` | `note` 안 |
| 콘솔 오류·실패한 요청 | `TypeError: pay is not a function` | `note` 안 |

## 3. 보낸 이슈는 어디서 보나

    https://chewgumi-qa-preview.netlify.app/qa-tool.html

맨 위 **[보내온 이슈]** 판에 사진과 함께 쌓입니다.

* **[고침]** — 다 고친 것을 목록에서 내립니다 (관리자로 로그인해야 눌립니다)
* **[개발자에게 보낼 글 복사]** — 통째로 복사해 그대로 붙여넣으시면 됩니다
* **[고친 것도 보기]** — 지난 것까지

## 4. 자주 막히는 것

**netlify 로그인을 물어봅니다**
시험 배포에 팀 로그인이 걸려 있습니다.
Netlify → `chewgumi-qa-preview` → Site configuration → Access & security → `Visitor access`

**고친 것이 시험 배포에 안 보입니다**
netlify 가 어느 가지를 보는지 확인해 주세요. `main` 만 보면 병합돼야 반영됩니다.

**사진 자리에 「관리자 로그인 필요」라고 뜹니다**
`qa-shots` 는 **비공개 창고**입니다. 주소만 알면 누구나 보던 것을 막았습니다.
사진을 **올리는 것**은 로그인 없이도 됩니다 (폰으로 손님 화면을 볼 때는 로그인하지 않으니까요).
**보는 것**은 `admins` 에 있는 사람만 됩니다 — `qa-tool.html` 에서 관리자로 로그인하시면
그때그때 한 시간짜리 주소를 받아 와 보여 줍니다.
사진 주소를 복사해 남에게 보내도 한 시간 뒤에는 열리지 않습니다.

**「사진은 못 찍었습니다」라고 뜹니다**
이슈 자체는 정상으로 들어갑니다. 사진만 빠진 것입니다.
사진은 `html2canvas`(jsdelivr)를 그때 불러와 그리는데, 그것이 막히면 이렇게 됩니다.

**관리자 화면이 안 열리고 「권한이 없습니다」가 뜹니다**
`assets/guard.js` 가 막는 것입니다. QA 계정으로 로그인하시면 됩니다.

**녹화가 안 됩니다**
아이폰 사파리는 화면 녹화를 지원하지 않습니다. 크롬·엣지에서 해주세요.

## 5. 어디에 쌓이나

| 곳 | 무엇 | 누가 읽나 |
|---|---|---|
| `qa_reports` | 사람이 적어 보낸 이슈 | `qa-tool.html` 의 [보내온 이슈] |
| `qa-shots` (창고) | 화면 사진 · **비공개** | 위 판의 그림 (관리자만) |
| `qa_events` | 누른 것·넣은 값 등 발자국 전부 | `qa-tool.html` 의 [기록] |
| `qa_guides` | 화면별로 무엇을 봐야 하는지 | (아직 화면에서 안 씁니다) |

`qa_reports` 는 **사람이 적은 것만** 쌓입니다. 발자국(`qa_events`)은 금방 길어져서
읽기 어렵기 때문에 따로 나눠 두었습니다.
