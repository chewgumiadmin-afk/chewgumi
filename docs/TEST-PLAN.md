# 2회차 · 구매 동선 (비회원)

**목적** 담기 → 주문서 → 결제창까지 끊기지 않는지. **결제는 누르지 않습니다.**

▶ **시킬 말**
```
https://shop.chewgumi.com 에서 비회원으로 구매를 시도해줘.
1. [1봉] 트래블잇(3,500원)을 장바구니에 담기
2. 장바구니로 가서 수량을 2개로 바꾸기
3. 주문하기 → 비회원으로 진행
4. 이름 홍길동 / 전화 010-0000-0000 / 주소는 우편번호 찾기로 아무거나
5. 결제수단 탭 3개(무통장·카드·가상계좌)를 각각 눌러보기
6. 결제 버튼은 누르지 말고, 화면을 캡처해서 보여줘

각 단계에서 오류나 이상한 점이 있으면 알려줘.
```

**확인할 것**
- [ ] 장바구니 상품 이미지가 담은 상품과 같은가
- [ ] 수량을 바꾸면 금액이 맞게 바뀌는가
- [ ] 5만원 미만이라 배송비 2,500원이 붙는가
- [ ] **가상계좌 탭을 고르면 버튼이 "가상계좌 발급받기"로 바뀌는가**
- [ ] 우편번호 찾기가 뜨는가

# 3회차 · 로그인 동선

**목적** 로그인이 유지되는지, 로그인 화면이 두 번 뜨지 않는지

▶ **시킬 말**
```
https://shop.chewgumi.com/login.html 을 열고
1. '로그인 유지' 체크박스가 있는지, 뒤로가기(HOME) 버튼이 누를 만한 크기인지 봐줘
2. 비밀번호에 abc123 을 넣어보고 어떤 안내가 나오는지
3. password 를 넣어보고 어떤 안내가 나오는지
4. 실제 계정으로 '로그인 유지'를 체크하고 로그인
5. 로그인 후 mypage.html 로 이동 — 로그인 화면이 다시 뜨는지
6. 새로고침을 3번 해보고 로그인이 유지되는지
7. index.html → mypage.html → cart.html 을 오가며 상단 메뉴에
   LOGIN 과 LOGOUT 이 동시에 보이는 곳이 있는지
```

**확인할 것**
- [ ] `abc123` → "8자 이상" 안내
- [ ] `password` → "너무 많이 쓰이는 비밀번호" 안내
- [ ] **마이페이지에서 로그인 화면이 안 뜨는가** (확인 중… 만 잠깐)
- [ ] 새로고침해도 로그인 유지
- [ ] LOGIN 과 LOGOUT 이 동시에 보이는 곳이 없는가 → **있으면 #95**
