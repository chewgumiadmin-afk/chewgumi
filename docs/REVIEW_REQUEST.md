```
아이디    test@chewgumi.com
```

## 3. 결제 완료까지 테스트 시나리오

### A. 무통장입금 — 현재 실제 가능

| 단계 | 확인 사항 | 기대 결과 |
|---|---|---|
| 1 | `/index.html` 접속 | 배너 4장이 순환, 상품 11개 표시 |
| 2 | 「듀잇 4개입」 클릭 | 가격 19,900원, 하단에 후기 표시 |
| 3 | [장바구니] → 수량 2로 변경 | 39,800원으로 갱신 |
| 4 | [주문하기] | 상품금액 39,800 + 배송비 2,500 = 42,300원 |
| 5 | 쿠폰 `WELCOME2000` 적용 | 40,300원으로 감소 |
| 6 | 이름·연락처 미입력 후 [주문하기] | "이름과 휴대전화를 입력해 주세요" |
| 7 | 정보 입력 후 [주문하기] | 주문번호 발급 + 계좌 안내 |
| 8 | 관리자 → 주문·배송 | 입금대기로 표시 |
| 9 | [입금확인] | 재고 차감 + 적립금 1% 지급 |
| 10 | 운송장 입력 후 [발송] | 택배사 자동 인식 |
| 11 | `/tracking.html` | 고객이 배송 조회 가능 |

**5만원 이상 주문 시 배송비가 무료로 바뀌는지도 확인 부탁드립니다.**
(듀잇 레몬민트 3개 = 59,700원)

### B. 카드 결제 — 공식몰 경유

| 단계 | 확인 사항 |
|---|---|
| 1 | 주문서에서 [카드 · 간편결제] 탭 선택 |
| 2 | 「신용카드 · 계좌이체 · 가상계좌 · 네이버페이」 표시 확인 |
| 3 | [공식몰에서 결제하기] → 공식몰 상품 페이지로 이동 |
| 4 | 공식몰에서 실제 결제 진행 |

> **이지페이 본계약이 완료되면** 자체 사이트에서 직접 카드 결제가 가능해집니다.
> 그 전까지는 위 방식으로 운영됩니다.

### C. 취소 · 환불

| 시점 | 환불액 | 처리 |
|---|---|---|
| 입금 전 | 0원 | 재고 복원 |
| 입금 후 발송 전 | 전액 | 재고 복원 + 적립금 회수 + 쿠폰 복원 |

## 5. 완료된 기능

**고객 화면 20개** — 메인, 브랜드 소개, 상품 상세, 장바구니, 주문서, 회원가입, 로그인,
마이페이지, 정기구독, 공지·후기·문의, FAQ, 이용안내, 약관, 배송조회, 위시리스트

**관리자 화면 18개** — 관리자 홈, 주문·배송, 재고·품절, 회원 조회, 게시물 관리,
게시판 설정, 메시지, 마케팅 발송, 정기구독 관리, AI 수출 비서, AI 개발 도우미,
규제·민원 대응, 연동 관리, 카페24 API, 수출·인증, QA 점검, 이슈 보드

**자동화**
- 주문 알림 이메일 (Resend · 월 3,000통 무료)
- 이슈 접수 시 담당자 메일 + GitHub 이슈 자동 생성
- 배송 조회 (운송장 번호로 택배사 자동 인식)
- 광고 발송 시 수신 동의자 필터 · 야간(21~08시) 자동 차단
- 전체 변경 이력 자동 기록 (추가·수정·삭제)

**검증**
- 정적 검사 38개 페이지 · 오류 0건
- 단위 테스트 + 시나리오 105건 전부 통과
