# 6단계 · 토큰 받기

## 하실 일

```
① 앱 대시보드 → 왼쪽 위 [도구] → [그래프 API 탐색기]
② 오른쪽 위 「Meta 앱」 → 츄구미 자사몰 선택
③ 「사용자 또는 페이지」 → 「페이지 액세스 토큰」
④ ChewGumi 츄구미 페이지 선택
⑤ [액세스 토큰 생성]
⑥ 권한 요청 창이 뜨면 모두 허용
```

## 긴 수명 토큰으로 바꾸기

**받은 토큰은 한 시간이면 만료됩니다.** 늘려야 합니다.

```
① 같은 화면 오른쪽 [ⓘ] 아이콘 클릭
② 「액세스 토큰 도구에서 열기」
③ [Extend Access Token] 누르기
④ 나온 긴 토큰을 복사
```

**두 달짜리**가 됩니다.

## 저에게 주실 것

```
① 긴 수명 토큰            (EAAxxxxx… 로 시작하는 긴 글자)
② 인스타 비즈니스 계정 ID   (숫자 · 아래에서 찾는 법)
```

### 계정 ID 찾는 법

그래프 API 탐색기에서 주소칸에 이렇게 넣고 실행하세요.

```
me/accounts?fields=instagram_business_account,name
```

나오는 결과에서 `instagram_business_account` 의 `id` 숫자입니다.

# 자주 막히는 곳

## 「사용할 수 있는 비즈니스가 없습니다」

**1단계를 안 하신 것입니다.** business.facebook.com 에서 먼저 만드세요.

## 인스타 계정 연결이 안 됩니다

```
□ 인스타가 프로페셔널(비즈니스) 계정인가
□ 페이스북 페이지가 있는가
□ 같은 계정으로 로그인했는가
```

## 토큰 생성 시 권한 오류

```
□ 앱에 Instagram 제품을 추가했는가
□ 페이지 액세스 토큰을 골랐는가 (사용자 토큰 아님)
```

## 인스타에서 「연결된 페이지 없음」

인스타 앱에서 직접 연결하는 방법도 있습니다.

```
인스타 앱 → 프로필 → 프로필 편집
→ 페이지 → 「페이지 연결」
→ ChewGumi 츄구미 선택
```
