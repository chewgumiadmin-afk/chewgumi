# Meta 비즈니스 인증 · 차례대로

인스타 API 를 쓰려면 **앱 심사**를 통과해야 하고,
그 전에 **비즈니스 인증**을 마쳐야 합니다.

```
비즈니스 인증   2~7일   ← 지금 하실 것
앱 심사        2~4주
```

**오픈과는 별개로** 천천히 진행하셔도 됩니다.

# 자주 거절되는 이유

| 이유 | 어떻게 |
|---|---|
| 서류와 입력값이 다름 | 한 글자까지 맞추기 |
| 서류가 흐림 | 스캔으로 다시 |
| 웹사이트에 회사 정보 없음 | 푸터에 사업자정보 표시 |
| 전화를 안 받음 | 낮에 받을 수 있게 |

```

□ 이용약관 주소          shop.chewgumi.com/terms.html    ← 있습니다
□ 화면 녹화 영상         제가 만들 화면으로 찍습니다
□ 용도 설명 (한글·영어)   제가 초안을 드리겠습니다
```

**녹화 영상은 앱이 실제로 작동하는 걸** 보여줘야 합니다.
인증이 끝나면 그 화면부터 만들겠습니다.
