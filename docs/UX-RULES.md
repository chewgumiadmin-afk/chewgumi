# 츄구미 UX 규칙

**화면을 만들거나 고칠 때 지켜야 할 것**들입니다.
QA 도구가 이 규칙으로 검사합니다.

---

# R1 · 값이 있으면 보여주기

## 규칙

**저장된 값이 있으면 입력칸이 아니라 읽는 모습으로** 보여줍니다.

```
✕  이름 [            ]   ← 값이 있는데 빈 칸
✓  이름  신현정  [고치기]
```

## 검사

```
DB 에 값이 있는데 input.value 가 비어 있나
저장 뒤에도 입력 화면이 그대로 남아 있나
```

## 예외

```
새로 만드는 화면 (주문서 · 가입)
값이 하나도 없는 경우
```

---

# R2 · 주소는 찾기로만

## 규칙

**우편번호와 주소는 직접 못 치게** 합니다.

```
우편번호  [ 04309 ] readonly  [주소 찾기]
주소      [ … ]     readonly
상세주소  [ … ]     직접 입력
```

**오타로 배송이 잘못 가는 것**을 막습니다.

## 검사

```
zipcode · addr1 입력칸에 readonly 가 있나
그 옆에 주소 찾기 단추가 있나
daum.Postcode 를 부르나
```

---

# R3 · 버튼은 반드시 일해야

## 규칙

**onclick 이 부르는 함수가 실제로 있어야** 합니다.

```
✕  <button onclick="filmSubmit()">  → filmSubmit 이 없음
```

## 검사

```
onclick·onchange 가 부르는 이름이 정의돼 있나
외부 js 까지 합쳐서 확인
```

---

# R4 · 같은 id 는 하나만

## 규칙

**한 화면에 같은 id 가 둘 이상이면** 안 됩니다.
코드가 앞엣것만 찾아 뒤엣것이 죽습니다.

## 검사

```
화면의 id 를 세어 중복이 있나
코드가 만드는 id 와 겹치나
```

---

# R5 · 무엇이 잘못됐는지 알려주기

## 규칙

**「실패했습니다」로 끝내지 않습니다.**

```
✕  저장에 실패했습니다.
✓  로그인이 풀렸습니다. 다시 로그인해 주세요.
✓  재고가 모자랍니다. 남은 수량 3개
```

## 검사

```
오류 문구가 「실패」 「오류」로만 끝나나
서버가 준 이유를 보여주나
```

---

# R6 · 돈이 바뀌면 미리 보여주기

## 규칙

**금액이 달라지면 저장 전에 알려줍니다.**

```
수량을 1개 → 2개로

  상품 금액      7,000원
  배송비        2,500원
  바뀐 결제 금액  9,500원

  추가로 3,500원을 결제하셔야 합니다
```

## 검사

```
수량·옵션을 바꾸는 화면에 금액 표시가 있나
바꾸는 즉시 다시 세나
```

---

# R7 · 되돌릴 수 없으면 두 번 묻기

## 규칙

**지우기·취소·탈퇴는 두 번** 확인합니다.

```
① 무엇이 지워지는지 알려주기
② 사유를 적게 하기
```

## 검사

```
delete·cancel·withdraw 를 부르는 곳에 confirm 이 있나
무엇이 지워지는지 문구에 있나
```

---

# R8 · 로그인 상태를 한 곳에서

## 규칙

**화면마다 따로 판단하지 않습니다.**

```
cgSession()   로그인 정보
cgTok()       토큰
cgRole()      역할
```

## 검사

```
localStorage.getItem('cg_sb') 를 직접 읽나
s.exp 만 보고 s.e 를 안 보나
```

---

# R9 · 상태에 맞는 메뉴

## 규칙

**로그인 여부에 따라 메뉴가 바뀝니다.**

```
로그인 안 함   LOGIN · JOIN US
로그인 함      MY PAGE · LOGOUT
```

**둘이 함께 나오면 안 됩니다.**

## 검사

```
login.html · join.html · mypage.html 링크가 동시에 보이나
navauth.js 를 부르나
```

---

# R10 · 고칠 행을 지정하기

## 규칙

**PATCH·DELETE 에 조건이 없으면** PostgREST 가 막습니다.

```
✕  /rest/v1/profiles              → 400
✓  /rest/v1/profiles?id=eq.UUID
```

## 검사

```
PATCH·DELETE 주소에 ?…=eq. 가 있나
```

---

# R11 · 기다리는 동안 알려주기

## 규칙

**서버를 부르면 무엇을 하는지** 보여줍니다.

```
[저장]  →  「저장하는 중…」  →  「저장되었습니다」
```

**버튼도 잠급니다.** 두 번 눌리면 안 되니까요.

## 검사

```
fetch 앞에 안내 문구가 있나
버튼에 disabled 를 거나
```

---

# R12 · 개인정보는 가려서

## 규칙

**주문번호만 알면 볼 수 있는 곳**에서는 가립니다.

```
비회원 조회   010-****-9634
본인 마이페이지  010-8497-9634
```

## 검사

```
guest_* 함수가 전체 번호를 돌려주나
메일 주소를 그대로 보여주나
```

---

# R13 · 못 하는 일은 미리 막기

## 규칙

**할 수 없는 상태면 버튼을 안 보여줍니다.**

```
배송 중   [수정] [취소] 안 보임
발송 후   반품 안내로
```

**눌렀다가 「안 됩니다」보다** 처음부터 없는 게 낫습니다.

## 검사

```
상태에 따라 버튼을 감추나
막힌 이유를 알려주나
```

---

# R14 · 링크가 살아 있어야

## 규칙

**없는 화면으로 보내지 않습니다.**

## 검사

```
href 가 가리키는 html 파일이 있나
http:// 로 된 링크가 있나
```

---

# R15 · 좁은 화면에서도

## 규칙

**폰에서 버튼이 겹치거나 잘리면** 안 됩니다.

```
글자 크기 16px 이상 (확대 방지)
버튼 높이 44px 이상 (누르기 쉽게)
가로 스크롤 없음
```

## 검사

```
input font-size 가 16px 미만인가
버튼 min-height 가 44px 미만인가
```
