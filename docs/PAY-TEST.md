## 테스트 1 · 카드 결제

### 하실 일

```
① https://shop.chewgumi.com/index.html?v=214
② 아래로 내려 「All Products」
③ [1봉] 트래블잇 카드 누르기
④ 팝업에서 [BUY NOW]
⑤ 이름 · 휴대전화 · 주소 넣기
⑥ [카드 · 간편결제] 고르기
⑦ [결제하기]
⑧ 결제창에서 카드로 승인
```

### 확인할 것

```
□ 팝업이 열리는가
□ 총 금액이 6,000원인가 (3,500 + 2,500)
□ 결제창이 열리는가
□ 승인 후 완료 화면이 나오는가
□ 장바구니가 비워졌는가
□ 주문 확인 메일이 오는가
```

### 그다음 — 관리자에서

```
https://shop.chewgumi.com/orders.html
```

```
□ 다시 로그인하라고 하지 않는가
□ 방금 주문이 목록에 있는가
□ 상태가 「결제 완료」인가
□ 금액이 6,000원인가

**처음 여는 기능입니다.** 가장 꼼꼼히 봐주세요.

```

③ 입금자명 넣기 (안 넣으면 주문자명)

```

□ 「에스크로가 적용됩니다」 안내가 있는가
□ 메일에도 계좌번호가 들어 있는가
```

**그 계좌로 6,000원을 넣으세요.**

□ 몇 분 안에 자동으로 확인되는가

## 테스트 4 · 발송 처리 + 에스크로 등록

**테스트 2 또는 3의 주문으로 하세요.** (에스크로 대상)

### 하실 일

```
① https://shop.chewgumi.com/orders.html
② 그 주문 찾기
③ 택배사 고르기 — CJ대한통운
④ 운송장번호 넣기 — 아무 숫자나 (예: 1234567890)
⑤ 상태를 「배송중」으로
⑥ [저장]
```

### 확인할 것

```
□ 「고객에게 발송 안내를 보냈습니다」가 뜨는가
□ 「에스크로 배송 등록까지 마쳤습니다」가 뜨는가
□ 고객 메일에 발송 안내가 오는가
   · 운송장번호가 들어 있는가
   · [배송 조회하기] 버튼이 있는가
□ orders.html 에서 상태가 「배송중」인가
```

> 카드·무통장 주문은 에스크로 등록이 안 뜹니다. **정상입니다.**

### 말로 처리해 보기

**orders.html 위쪽 「말로 처리하기」 칸에**

```
20260824 주문 CJ대한통운 1234567890으로 발송 처리해줘
```

```
□ [어떻게 할지 보기] 를 누르면 미리보기가 나오는가
□ [이대로 처리하기] 를 누르면 반영되는가
```
