## ① index.html — 한국어가 아닌 브라우저에서 홈이 통째로 멈춤  ★블로커

**현상** 브라우저 언어가 한국어가 아니면 홈 화면의 상품 옵션·상세·장바구니가 전부 동작하지 않습니다.

**원인** `if (!(navigator.language||'ko')...startsWith('ko')) setLang('en');` 가
`let cgUsdPerKrw = null;` 보다 **먼저** 실행됩니다. `let` 은 선언 전에 못 읽으므로
`ReferenceError: Cannot access 'cgUsdPerKrw' before initialization` 이 나고,
그 아래 스크립트(상품 구성 `CG_OPTIONS`, 상세, 장바구니)가 **전부 정의되지 않습니다.**

**수정** `let` → `var`. 한국어/영어 두 경우 모두 오류 0건 확인.

# 5차 — 주문서 · 결제 동선

## ㉗ 가상계좌를 골라도 무통장입금 주문이 만들어집니다  ★★ 오픈 블로커

결제수단에서 「가상계좌 · 에스크로 적용」을 고르면 에스크로 안내가 뜨는데,
결제 버튼 문구는 **「주문하기 (무통장입금)」** 그대로이고 실제 주문도 **무통장입금**입니다.

**원인** `checkout.html` 뒤쪽에서 `setPay` 를 **덮어쓰는 스크립트**가 있습니다.
이 함수는 `window.payType` 만 바꾸고, `t === 'vbank'` 일 때는 원래 함수를 **부르지 않습니다.**
주문을 만드는 코드가 읽는 것은 안쪽의 `let payType` 이라 계속 `'bank'` 로 남습니다.

```
가상계좌 선택 후 실제 상태
  window.payType = 'vbank'     ← 아무도 안 읽음
  payType        = 'bank'      ← 주문 생성이 읽는 값
  버튼 문구       = '주문하기 (무통장입금)'
  vDepositor 입력값 → 어디에서도 저장 안 됨
```

**수정** 가상계좌 탭을 감췄습니다(`CG_VBANK_READY`). 가상계좌는 카드 결제창(이지페이) 안에서
이미 선택 가능하므로 손님이 못 하게 되는 일은 없습니다.

## ㉘ 토스 결제 위젯이 한 번도 만들어지지 않습니다

`let PRODS={}, amount=0, widgets=null;` — `widgets` 에 값을 넣는 곳이 **저장소 전체에 없습니다.**
그래서 `widgets.requestPayment(...)` 경로는 `TypeError` 가 나고, 사람에게는
**「결제가 취소되었습니다」** 로만 보였습니다(R5 위반).

**수정** 취소와 미연결을 구분해 안내. 지금 실제 결제는 **이지페이(카드)** 와 **무통장입금** 두 갈래입니다.

## ㉙ 주문 생성이 실패했는데도 '주문됨'으로 표시하던 순서

`od=await res.json()` 직후 `cgMarkOrdered(od.orderNo)` 를 부르고 그 다음에 `res.ok` 를 검사했습니다.
순서를 바꿔 성공을 확인한 뒤에만 표시하도록 했습니다.
