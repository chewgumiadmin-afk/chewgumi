# 자동 테스트

## 실행

```bash
node tests/flow-test.js
```

Node.js 18 이상이면 별도 설치 없이 실행됩니다.

## 검증 항목

| 구분 | 내용 |
|---|---|
| 인증 | 운영자 로그인, 권한 확인 |
| 기초 데이터 | 상품·재고·계좌·쿠폰·후기·구독 상품 |
| 주문 흐름 | 주문 생성 → 금액 계산 → 입금확인 → 재고차감 → 발송 → 취소 → 재고복원 |
| 서버 기능 | 카페24·개발도우미·알림·마케팅·수출비서·영상·구독 함수 응답 |
| 접근 권한 | 비로그인 상태에서 주문·회원·비밀키 조회가 차단되는지 |

## 결과 읽기

```
✓ 정상    ✗ 문제    - 보류(설정 미완료)
```

문제가 하나라도 있으면 종료 코드 1을 반환하므로,
자동 배포 전 검사에 넣으실 수 있습니다.

## 주의

테스트가 실제 주문을 만들고 재고를 차감했다가 되돌립니다.
운영 중에 돌리셔도 흔적은 남지 않지만, 주문이 몰리는 시간은 피하시는 것이 좋습니다.
