    이 화면은 넣기 전용입니다. 이미 저장된 열쇠를 읽어오지 못합니다. 화면에는 「설정됨 / 비어있음」만 보입니다.

    저장하는 것 — 각 서비스의 API 키와 아이디, 그리고 넣으신 시각·성공 여부 기록. 모두 서버 금고에 들어가며 이 화면으로 다시 나오지 않습니다.

    저장하지 않는 것 — 주민등록번호, 사업자등록증 같은 서류, 각 서비스의 로그인 비밀번호. 그런 것은 해당 서비스 사이트에 직접 입력하시는 것이고 저희는 받지 않습니다.

    서류를 올리실 때 — 카카오 비즈니스 심사처럼 서류가 필요한 곳이 있습니다. 그 사이트에 올리실 때 주민번호 뒷자리와 전화번호는 꼭 가려 주세요. 가리지 않아 반려되는 경우가 가장 많습니다.

    도우미 채팅에는 열쇠를 적지 마세요. 적으시면 저장하지 않고 지우시라고 안내합니다. 열쇠는 카드의 입력칸에만 넣어 주십시오.
