# 츄구미 QA 기록 · 크롬 확장

화면을 쓰면서 **누른 곳 · 넣은 값**을 기록하고,
이상한 것을 **그 자리에서 적을 수 있게** 합니다.

---

## 넣는 법 (한 번만)

```
① 크롬 주소창에  chrome://extensions
② 오른쪽 위 「개발자 모드」 켜기
③ 왼쪽 위 [압축해제된 확장 프로그램을 로드합니다]
④ 이 폴더(cgqa)를 고르기
```

**끝입니다.** 오른쪽 위 확장 아이콘에서 압정을 눌러 고정해 두세요.

---

## 쓰는 법

```
① 츄구미 사이트를 엽니다
② 확장 아이콘을 누르면 오른쪽에 창이 열립니다
③ [기록 시작]
④ 평소처럼 쓰시면 됩니다
⑤ 이상한 게 보이면 적고 [버그]
⑥ 끝나면 [글 복사] → 개발자에게 붙여넣기
```

## 녹화까지 하시려면

```
[● 녹화] → 「Chrome 탭」 → 츄구미 탭 고르기
```

**끄면 영상이 내려받아집니다.**
기록에 `[01:23]` 처럼 시각이 붙어 영상과 맞춰 볼 수 있습니다.
